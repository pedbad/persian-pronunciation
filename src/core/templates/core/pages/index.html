{% c card/description %} Persian script leaves its short vowels unwritten, so a learner cannot see from the page how a word should sound. Record yourself, and get feedback on one vowel at a time. {% endc %} {% endc %} {% c card/content %}

Say a word aloud and the engine lines your recording up against a native speaker’s, vowel by vowel. Each vowel comes back coloured by how close you were, with a short hint on what to change. Built for Cambridge Language Centre CULP Persian learners, with a pilot planned for Michaelmas 2026.

{% icon 'dashboard' class_='h-6 w-6 text-foreground/80' %} {% c card/title %}How it works{% endc %}
{% c card/description %} Four stages, from pressing record to reading the result. {% endc %} {% endc %} {% c card/content %}
  1. 1 Record the word. The word appears in Persian script with its meaning. You say it once.
  2. 2 Check it is the right word. Speech recognition acts as a gatekeeper. Say a different word and you are asked to try again rather than given a misleading score.
  3. 3 Line it up and compare. Forced alignment finds where each vowel starts and ends, then your vowels are compared against two native recordings — the closer of the two is the one you are scored against.
  4. 4 Read the feedback. Each vowel is scored on how it sounded and how long it was held, then shown with a hint on what to change.
